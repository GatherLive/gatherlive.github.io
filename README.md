# Gather

Free, open-source live quizzes for everyone.

[Open Gather](https://gatherlive.github.io/)

- Join with a six-digit code. No guest account needed.
- 11 question types with images, timers, and leaderboards.
- Save quiz sets and host multiple rounds with optional rewards.
- Configurable countdowns, reconnect support, and downloadable results.
- Host announcements and invitation-only chat with replies and emoji reactions.
- Announcements and chat stay hidden during countdowns and questions.
- Copy an AI quiz prompt, import JSON, and delete your account anytime.

No ads, analytics trackers, or data sales. Accounts, quizzes, and results are stored only to run the service. One invitation code unlocks chat for a host account and its future quizzes. Chat and announcements are deleted when the quiz ends; abandoned rooms expire after 24 hours.
