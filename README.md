# Gather

Free, open-source live quizzes for everyone.

[Open Gather](https://gatherlive.github.io/) · [User guide](how-to-use.md) · [Code structure](ARCHITECTURE.md) · [Buy me a coffee](https://buymeacoffee.com/gatherlive)

## Features

| Feature | What you can do |
| --- | --- |
| Live quizzes | Join with a six-digit code and a name. No participant account needed. |
| Autoplay | Schedule a start and choose the pace between questions and rounds. |
| Play modes | Host a quiz, play solo, or join in with friends. |
| Live game | Reveal answers on an avatar stage with manual or timed turns. |
| Competition | Use lives, review notes, duplicate and secret answers, and custom teams. |
| Question types | Use 11 formats, including multiple choice, word clouds, sliders and image pins. |
| Pin on image | Place the correct dot and resize a circle or box for accepted answers. |
| Game settings | Choose timers, scoring, shuffling, rounds, rewards and leaderboards. |
| Room tools | Use optional join verification, chat with typing indicators and mentions, and countdown announcements. |
| Quiz library | Organise reusable quizzes with tags, search and hosting filters. |
| Quiz files | Import or export JSON, start with a sample or copy a host or Solo play prompt. |
| Quiz editor | Reuse question timing and points and undo or redo edits. |
| Detailed results | Review responses, winners and remaining lives. Download PDF, HTML or CSV reports. |
| Images | Add question and answer images, with conservative photo optimization. |
| Settings | Manage your account, saved data, usage and requests for higher limits. |
| Site news | Read updates beneath the header and dismiss them on your device. |

No ads or data sales. Information is used to provide and secure the service.
